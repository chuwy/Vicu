# Vicu 2.6.0

Vicu 2.6.0 names your computer in Vikunja's list of sessions and shows the custom list icons themselves when you choose one. Update the phone app to 2.6.0 at the same time: it brings guided organizing and the weekly review to Android and iOS.

If you find a rough edge, please [open an issue](https://github.com/rendyhd/vicu/issues).

### Changes

- **Sessions in Vikunja.** Vikunja's Settings, Sessions now names Vicu and the computer, for example "Vicu/2.6.0 (Windows; DESKTOP-4K2H1)", instead of a long browser string. A session from before keeps its old name until that computer signs in again.
- **Custom list icons.** The New list and Edit list dialogs show the icons themselves to choose from, instead of a list of names. The arrow keys, Home and End move between them.
