# Vicu 2.2.0

Vicu 2.2.0 ships together with Vicu 2.2.0 for Android and iOS. Your settings now follow you: the Inbox and the order of your tasks are the same in the desktop app and on every phone, iPhone and iPad. It also makes the data Vicu keeps on your Vikunja server for itself safer, above all in shared projects. Update your phones to 2.2.0 at the same time.

There is no 2.1 for the desktop; the version jumps to 2.2.0 so it matches the mobile apps. The phone side is in the [Vicu 2.2.0 for Android and iOS notes](https://github.com/rendyhd/Vicu-Mobile/releases/tag/v2.2.0). If you find a rough edge, please [open an issue](https://github.com/rendyhd/vicu/issues).

### Your Inbox and task order sync

- **The Inbox project is the same on every device.** The first device you update offers its Inbox to the others; a device whose Inbox was different switches to it and tells you so. Choosing another Inbox (Settings, Projects) changes it everywhere. A new installation suggests your Inbox during setup.
- **Sort the tasks of a project your way**, with thanks to [@Pegoku](https://github.com/Pegoku): Due date then manual (the default), Due date then priority, Manual, Priority, Title, Newest first or Oldest first. Pick an order for every project in Settings, Projects, Display, or for one project with Sort tasks in its menu. The Inbox has a sort button in its header. A project without its own order follows its parent's. Settings says how many projects have their own order, and Reset puts them all back to the default.
- In Manual order you can drag every task; in the default order the undated ones; in the sorted orders none.
- **Move a task with the keyboard**: Alt+Shift+Up or Down (Option+Shift on a Mac) moves the selected task one place, and right-clicking a task offers Move up and Move down. They follow the same rule as dragging.
- Today, Upcoming, Anytime and custom lists keep their own order.

### Refresh

- **Press F5** (or Ctrl+R, Cmd+R on a Mac, or View, Refresh) to read the page you are on again from the server, without leaving it. It also picks up projects, labels, sharing, custom lists and settings changed on another device. Changes still waiting to be sent go first. Ctrl+R (Cmd+R) used to reload the whole window; that is now View, Reload window (Ctrl+Shift+R, Cmd+Shift+R on a Mac). Refresh is also in the command palette.

### Sidebar

- **Show task count in the sidebar** (Settings, Projects) shows how many open tasks each project has, with or without the progress rings. It is off until you turn it on.

### Safer hidden data

Vikunja has no place for an app's own data, so Vicu keeps custom lists, routines and now your settings in tasks it hides.

- **Shared projects no longer mix people's data.** Before, if your Inbox (or another project holding Vicu's hidden tasks) was shared, the other person's Vicu took your custom lists and routines as its own. Now each person's Vicu uses only the hidden tasks they created. Lists or routines that were already mixed cannot be told apart afterwards: delete the ones that are not yours.
- **Signing in as someone else on the same server starts clean.** Before, a second account on the same Vikunja server kept the first account's custom lists and Inbox and synced them into its own. Now that data is cleared when a different user signs in; your device settings (theme, shortcuts, Quick Entry) stay.
- Every Vicu hidden task is hidden from your lists, counts, reminders and search, including ones reopened or edited in Vikunja's web app, which keep working.
- Hidden data a newer version of Vicu wrote is kept and never overwritten; a routine saved by a newer version says so instead of asking for repair.
- Deleted custom lists older than 90 days are cleaned up, so the desktop app and the phone no longer rewrite your custom lists on every sync, and a second copy of your custom lists left by two devices is removed.
- A version older than 2.2.0 shows the new settings task as one done task in the Logbook and search until it updates.

### Fixes

- **Discard unsynced changes now covers custom lists and settings.** The sync panel lists custom-list and settings changes that have not reached the server yet, under Lists and settings, with Sync now and Discard. Discard puts them back to what the server last had.
- Adding a task with a label to a custom list that filters by that label no longer says "it does not currently match this list's filters" while the task appears in the list ([#39](https://github.com/rendyhd/vicu/issues/39)).
